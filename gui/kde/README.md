# SCSKiller KDE UI

The Linux UI is intended to be a Qt 6 / KDE Kirigami application.

Design goals:

- inherit Plasma light/dark preference and platform styling;
- use KDE/Qt fonts, colors, icons, dialogs, and controls;
- share SCSKiller concepts with the Windows app without sharing WinUI implementation code;
- remain usable outside Plasma on other Qt desktop environments.

The UI project will be added once the Linux core contracts are wired to a real executable.
